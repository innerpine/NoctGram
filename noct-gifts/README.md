# Noct Gifts

Рабочий Telegram Mini App с общим аккаунтом NoctGram: кейсы, апгрейдер, подарки, баланс и пополнение через действующего платёжного бота.

## Запуск

Node.js 22 или новее. Скопировать `.env.example` в `.env`, задать адрес API основного NoctGram и HTTPS-адрес мини-аппа. Запустить `node --env-file=.env server.mjs`. Открывается `/Noct%20Gifts%20App.dc.html`, порт по умолчанию 4186.

Сервер слушает `127.0.0.1`. Для публичного доступа нужен HTTPS reverse proxy на этот порт, сохраняющий исходный Host (`proxy_set_header Host $host;` в nginx). Разместить мини-апп в корне отдельного домена.

Для входа открыть @noctgramdrop_bot. В обычном браузере показывается кнопка перехода в Telegram; локальных балансов и поддельных профилей нет. Telegram нужно предварительно привязать в NoctGram → Noct Stars → Telegram.

Порядок выкладки API, миграция общей базы и настройка бота описаны в `../NOCT_GIFTS_BRIDGE.md`.

## Поведение

Сервер списывает Stars и выдаёт подарок до начала прокрутки. Полученный подарок сразу доступен в профиле NoctGram; анимация только показывает результат. Кнопка «Открыть ещё раз» запускает отдельное платное открытие с показанной ценой. При неудачном апгрейде исходный обычный подарок расходуется.

«Без прокрутки кейса» отключает только прокрутку. Системное уменьшение движения учитывается для всех анимаций. При успешном апгрейде показываются текст и однократное конфетти. Из макета удалены нарисованные часы, батарея и другие системные индикаторы.

Незавершённый запрос хранится в sessionStorage с владельцем и ключом. При сетевой ошибке кнопка проверки повторяет тот же запрос; браузер не выбирает новый результат и не начисляет подарки самостоятельно.

## Ресурсы

Изображения и Lottie подарков, логотип и Noct Stars взяты из проекта NoctGram. Иконки кейсов подготовлены для этого интерфейса. Lottie поставляется с `Lottie-LICENSE.md`; `support.js` — runtime исходного DC-экспорта, использует React CDN. Шрифты загружаются с Google Fonts.

Анимации цифр и модальных окон адаптированы из открытых примеров transitions.dev. Конфетти — собственная Canvas-анимация по визуальному референсу https://transitions.dev/detail.html?t=confetti-burst; закрытый Pro-код не используется.
