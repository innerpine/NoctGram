# «Кто-нибудь не спит?» — мультфильм про NoctGram

62 секунды, 1080×1080, 24 кадра/с, в стиле бумажной аппликации. Лёва — одиночка, которого не замечают в школе. Ночью он пишет «кто-нибудь не спит?» и запускает самолётик, но тот падает в лужу. Потом он заходит в NoctGram, публикует рисунок луны, находит друзей, и окна города загораются. В финале самолётики собираются в луну, а за ней появляется логотип.

Каждый кадр рисуется кодом на Canvas (`cartoon.js`), музыка и звуки синтезируются в `music.py`. Готовое видео в репозиторий не кладётся: его можно пересобрать.

## Посмотреть в браузере

Откройте `index.html` через любой статический сервер из корня репозитория, чтобы подтянулся логотип из `public/assets`:

```
npx http-server . -p 8080   # затем http://localhost:8080/promo/cartoon/?t=0
```

`?t=30` начинает с 30-й секунды, пробел ставит на паузу. Звук в браузере не играет, он есть только в собранном видео.

## Собрать MP4

Нужны Node 22, Playwright с Chromium, Python 3 с numpy и ffmpeg.

```
python3 promo/cartoon/music.py /tmp/cartoon.wav
node promo/cartoon/render.mjs --out /tmp/cartoon.mp4 --audio /tmp/cartoon.wav
```

Отдельные кадры для проверки: `node promo/cartoon/render.mjs --stills 3,12.5,40 --dir /tmp/frames`.
Если playwright или ffmpeg не лежат в стандартных местах, укажите `PLAYWRIGHT_MODULE=/путь/к/playwright` и `FFMPEG=/путь/к/ffmpeg`.

## Раскадровка

| Время | Сцена |
|---|---|
| 0–8 с | Коридор: все смеются, Лёву толкают, рисунок с луной падает, по нему проходят |
| 8–16 с | Ночной дом: ужин, игра, разговор, а в последнем окне грустный Лёва |
| 16–24 с | Пишет «кто-нибудь не спит?», складывает самолётик, тот падает в лужу |
| 24–30 с | Телефон вибрирует: «Ночью тоже кто-то рядом» |
| 30–41 с | Публикует рисунок, 0 лайков, почти удаляет, и тут приходят комментарии |
| 41–52 с | Радость, звонок втроём под общий трек, канал «ночные рисунки», окна города загораются |
| 52–62 с | Снова пишет, самолётик летит, самолётики собираются в луну, титр и логотип |
