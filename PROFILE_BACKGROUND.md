# Фон профиля и музыкальная активность

В «Редактировать → Дизайн → Фон профиля» доступны обычный фон, градиент по цветам оформления, цвета баннера (или аватара без баннера) и собственные два цвета. Интенсивность регулируется с предпросмотром. Сохранение доступно личным профилям с Noct Premium; выбор виден посетителям профиля. После окончания Premium оформление хранится и вернётся при продлении.

Музыкальная карточка расположена справа от имени на широком экране и под данными профиля на телефоне. Дополнительные юзернеймы находятся рядом со статусом сети. Фон карточки и её акценты берутся из обложки трека. Палитры вычисляются один раз на изображение и кэшируются; недоступные изображения дают нейтральный акцент.

## Обновление существующей локальной копии

После обновления кода сохраните резервную копию своей локальной базы и примените только ещё не применённые миграции. Для копии, уже обновлённой до `0032_presence_privacy`, нужна одна новая миграция:

```powershell
npx wrangler d1 export DB --local --config wrangler.local.json --output work/before-profile-background.sql
npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0033_profile_background.sql
npm run dev
```

Миграция добавляет поле `profile_appearance.background` с пустым значением по умолчанию. Она не изменяет профили, переписку, музыку или подарки. Не применяйте её повторно и не заменяйте свою базу базой другого разработчика. Для новой установки используется вся цепочка миграций.

## Проверки

`node --test tests/profile-background.test.mjs tests/image-palette.test.mjs tests/combined-migrations.test.mjs` проверяет права Premium, сохранение и чтение другим пользователем, строгую валидацию цветов, совместимость со старым клиентом, окончание Premium, палитру обложки и обновление обеих исторических веток базы без потери данных.
