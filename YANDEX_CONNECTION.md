# Проверка соединения с Яндекс Музыкой

На странице «Музыка → Сервисы → Яндекс Музыка» есть кнопка «Проверить соединение с Яндексом». Она запрашивает `/account/status` с сервера Noctgram без пользовательского токена. Успех означает доступность API, но не подтверждает токен или подписку.

При локальном запуске запрос отправляет компьютер, где работает `npm run dev`. VPN-расширение в браузере не меняет этот маршрут. Нужен VPN, охватывающий сетевое подключение сервера, либо размещение Noctgram на сервере с доступом к Яндексу. Глобальные DNS, прокси и сертификаты пользователя приложение не меняет.

Коды ошибок:

- `YANDEX_DNS_ERROR`: адрес API не удаётся определить через DNS.
- `YANDEX_TIMEOUT`: не удалось дождаться подключения или ответа.
- `YANDEX_TLS_ERROR`: ошибка проверки защищённого соединения. Проверка сертификата не отключается.
- `YANDEX_NETWORK_ERROR`: другая сетевая ошибка до получения ответа API.
- `MUSIC_RECONNECT`: API ответил, но отклонил токен. Это отдельная ситуация.

Во время диагностики 7 сентября 2026 локальный DNS вернул `ENOTFOUND` для `api.music.yandex.net`. Независимый DNS вернул адрес, но прямая попытка соединения с ним завершилась по таймауту. Это не доказательство неисправности токена и не повод автоматически помечать существующее подключение как истёкшее.

После включения VPN снова нажмите проверку, затем «Подключить Яндекс Музыку». При ошибке подключения токен остаётся только в поле текущей страницы для повторной попытки; после успешного подключения поле очищается. В файлы, URL и журналы токен не записывается, в базе он хранится зашифрованным.

Проверка без реального аккаунта: `node tests/yandex-transport.test.mjs` и `node tests/music-services.test.mjs`.
