# Темы диалогов

Меню из трёх точек рядом с блокировкой открывает «Оформление чата». Восемь статичных палитр меняют фон, пузырьки сообщений и акцент кнопки отправки. Предпросмотр находится внутри окна выбора; закрытие без применения не меняет диалог. Фоны состоят из мягких градиентов, без анимации, внешних изображений и размытия каждого сообщения.

«Только у меня» сохраняет личную тему для пары пользователей. «Для обоих» меняет общую тему и снимает личное переопределение у выбравшего её пользователя. Личная тема второго участника сохраняется. «Вернуть общую тему» удаляет только собственное переопределение и показывает актуальную общую тему. Настройки хранятся на сервере, поэтому сохраняются при повторном входе и на других устройствах.

Миграция `drizzle/0019_chat_themes.sql` добавляет одну таблицу с составным первичным ключом упорядоченной пары пользователей. Она уже применена к локальной базе. Ответ сообщений с `includeTheme=1` содержит настройки вместе с перепиской; отдельного таймера или дополнительного HTTP-опроса нет. Счётчик версии не позволяет старому ответу заменить более свежий выбор. Личное оформление собеседника клиенту не передаётся.

Общая тема меняется только при доступном общении и праве записи. При блокировке можно менять свою личную тему сохранённой переписки. Отправителя всегда определяет серверная сессия, идентификаторы владельца настройки от клиента не принимаются. Изменение темы не создаёт сообщений и уведомлений.

`tests/chat-themes.test.mjs` проверяет обе стороны диалога, приоритет личных настроек, возврат к общей теме, одновременный выбор, изоляцию разных чатов, приватность, валидацию и отсутствие записей при опросе на изолированной SQLite. Реальным пользователям тестовые сообщения не отправляются.
