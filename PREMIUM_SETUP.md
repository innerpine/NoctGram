# Noct Premium

«Редактировать → Дизайн»: шесть палитр профиля, градиент имени, собственный вращающийся текст вокруг аватара (до 48 графем), GIF/MP4/WebM-аватар до 10 МБ. Значок Premium появляется автоматически справа от имени и получает цвета профиля. Для обводки использован собственный SVG textPath по мотивам [Spinning Text](https://magicui.design/docs/components/spinning-text), без новой зависимости. Оригинальный PNG значка и сцены Premium/Stars сохранены.

Для аватара сохраняются два файла: исходная анимация и квадратное неподвижное PNG-превью. Превью показывается при reduced motion, отключении анимаций, скрытии вкладки или уходе аватара за экран. Локальный переключатель находится в «Дизайн» и «Приватность»; он доступен всем. Новые обычные аватары, в том числе при регистрации и создании канала, должны быть статичными. Ранее сохранённые аватары не переписываются этой миграцией.

## Обновление базы

На базе с миграциями 0000–0007 один раз применить:

```powershell
npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0008_spotty_madame_web.sql
```

В основной локальной базе и `work/features-qa` миграция уже применена. Для новой базы применить все SQL-файлы по порядку согласно CONTRIBUTING.md. Реальные аккаунты и файлы не входят в Git.

## Тестовая активация

Платежей пока нет. Для разработки добавить в личный `.env`:

```dotenv
NOCT_PREMIUM_TEST_MODE=1
```

После перезапуска сервера меню Noct Premium покажет кнопку бесплатной активации на 30 дней. Один период на аккаунт, повтор запроса не продлевает его. Нет автопродления, списаний и подключения платёжного сервиса. В `.env.example` режим выключен; не включать его на публичном сервере.

`premium_entitlements` хранит начало, окончание и отзыв доступа. `profile_appearance` хранит только настройки косметики. Запрос оформления не может выдать Premium; он сохраняет данные только текущего человека с действующим доступом. Каналы не наследуют Premium владельца. Read-only и блокировка запрещают изменения. По истечении/отзыве доступа API выдаёт обычное оформление и статичное превью, настройки сохраняются для возможного продления. Детали внутренней выдачи не входят в публичный профиль.

Для платного запуска требуется проверяемый сервером webhook платёжного провайдера, идемпотентная выдача/продление, обработка отмен и возвратов. Клиентский результат оплаты не должен сам изменять entitlement. Публичного endpoint произвольной выдачи нет.

## Chrome Flow

«Редактировать → Дизайн → Chrome Flow» включает металлическую обводку в цветах профиля. Ползунок меняет темп от спокойного к быстрому, предпросмотр обновляется сразу. Настройка хранится на сервере: параметр 3–26, по умолчанию 11; длительность цикла равна параметру × 0,75 секунды, как в предоставленном `unixgram-design-system.html`. Рамка видна в профиле, ленте и списках, совместима с текстовой обводкой. При отключённом движении остаётся статичной. Под-юзернеймы Premium-профиля используют основной цвет выбранной палитры.

Для базы с миграциями 0000–0008 один раз применить `drizzle/0009_dazzling_eternity.sql` той же локальной командой выше. В основной локальной и QA-базах она уже применена. Старые клиенты, которые не передают параметры Chrome, сохраняют текущую рамку и темп.

## Автоматические проверки

`npx tsc --noEmit`, `npm run lint`, `npm run build`. Для API-теста использовать только отдельную локальную QA-базу со всеми миграциями и `tests/fixtures/moderation.sql`:

```powershell
npx wrangler dev --config dist/server/wrangler.json --ip 127.0.0.1 --port 8787 --persist-to work/features-qa --var NOCT_PREMIUM_TEST_MODE:1
# В другом терминале:
node tests/premium.integration.mjs
```

Тест создаёт собственные искусственные аккаунты и меняет сроки только их подписок в QA-базе. Он проверяет моментальную активацию, повтор запроса, защиту от подделки Premium, срок/отзыв доступа, принадлежность файлов, публичные проекции, границы каналов и read-only. Не запускать на рабочей базе.
