# NoctGram для Android

Нативный клиент на Kotlin и Jetpack Compose для существующего сервера https://noctgram.com — тот же API, что у iOS-приложения (`mobile/ios`, ветка `markdev/noctgram-ios-*`). Android 8.0 (API 26) и новее. Идентификатор приложения — `com.noctgram.app`.

## Что есть

- Оформление как на сайте: система из `DESIGN.md` (чёрная основа, карточки #0C0C0C, меню #161616, белый текст четырёх яркостей, границы 8 и 14 %), шрифт Inter и слово «Noctgram» в Instrument Sans, иконки из того же набора lucide, что на сайте. Белая «таблетка» — главное действие экрана, вторичные кнопки полупрозрачные со скруглением 12 dp, поля ввода и переключатель ленты повторяют сайт. Загрузка показывается заготовками карточек, пустые списки и ошибки — отдельными состояниями.
- Вход по одноразовому коду из письма (`/api/auth/start` → `/api/auth/verify`), первичная настройка имени и юзернейма, выход.
- Плавающая панель вкладок в духе Telegram: «Лента», «Чаты» с бейджем непрочитанного, «Профиль» с аватаром аккаунта.
- Лента «Для вас» и «Подписки» с карточкой «Что нового?»: текст со сворачиванием после восьми строк, блок кода с кнопкой копирования, фото сеткой, опросы с голосованием, 18+ размывает фото до нажатия, лайки, закладки, просмотры и Stars, меню «Скопировать ссылку», догрузка и обновление жестом. Автор открывается по нажатию.
- Новая публикация: текст, блок кода с языком, до четырёх фото из системной галереи, опрос на 2–6 ответов, отметка 18+.
- Комментарии: последняя страница, догрузка предыдущих, ответ.
- Профили, свой и чужие: обложка (включая «Жидкое» — пока статичная размытая аватарка), оформление Premium (палитра, градиент имени, значки, текст вокруг аватара, Chrome Flow, фон карточки), юзернеймы и анонимный номер в цвете профиля, присутствие, описание. Счётчики кликабельны: подписчики и подписки открывают списки, публикации прокручивают к постам. Подписка и «Написать».
- Редактирование своего профиля (имя, описание, аватар, обложка или «Жидкое») и экран «Дизайн» с живым предпросмотром — те же настройки, что на сайте; сохранение требует Noct Premium.
- Чаты: общий список личных диалогов и групп, переписка с опросом сервера раз в три секунды, разделители по дням, пузыри с хвостиками, отметки прочтения, ответы и вложения, отправка текста, а в личных диалогах ещё и фото. Секретные чаты показываются, но читаются только на сайте.

Кошелёк, отправка Stars, Маркет, подарки, видео, реакции на сообщения, поиск, создание групп и push-уведомления ещё не перенесены — для них пока остаётся сайт.

## Как устроено

Сторонних библиотек в приложении нет, кроме AndroidX и Compose: сеть — `HttpURLConnection`, JSON — `org.json`, шифрование — Android Keystore.

- `NoctApi.kt` — клиент сервера. Один зашитый HTTPS-адрес, только пути `/api/…`, без редиректов, ответы ограничены по размеру (8 МБ JSON, 25 МБ медиа). Ошибки сервера приходят как `ApiException` с русским текстом. Ответ 401 (кроме шагов входа) стирает сессию на устройстве.
- `Session.kt` — сессия. Сохраняются только два cookie сервера (`noct_session`, `noct_email_challenge`) и только если они `Secure`, `Path=/`, с токеном из 64 hex-символов и сроком жизни. На диске они лежат зашифрованными ключом AES-GCM из Android Keystore; файл исключён из резервных копий. Нечитаемые данные означают просто «не вошёл».
- `App.kt` — состояние входа, стек открытых экранов и панель вкладок. Экраны: `Auth.kt`, `Feed.kt`, `Compose.kt` (публикация и комментарии), `Profile.kt` (профиль и списки подписок), `ProfileEdit.kt` (редактирование и дизайн), `Chats.kt`.
- `Ui.kt` — дизайн-система: цвета и шрифты сайта, кнопки `NoctButton` и `IconAction`, поля `NoctField` и `MessageField`, переключатель `Segmented`, `Chip`, заготовки загрузки, пустые состояния и ошибки, оформление Premium (`Look`, `DisplayName`, `ProfileAvatar`) и загрузка картинок: медиа отдаётся только вошедшему аккаунту, поэтому идёт через `NoctApi`.
- `Lucide.kt` — иконки сайта. Файл создаёт `node tools/lucide-to-compose.mjs` из пакета `lucide-react` в корне репозитория. Чтобы добавить иконку, впишите её имя в скрипт и запустите его.
- Шрифты лежат в `app/src/main/res/font`. Лицензии шрифтов (SIL OFL 1.1) и иконок (ISC) — в `licenses/`.

Осознанные упрощения помечены в коде комментариями `ponytail:` — кэш картинок только в памяти, нет видеоплеера, «Жидкое» статичное.

## Сборка

Локально нужны JDK 17+ и Android SDK (платформа 35, build-tools 35). Путь к SDK — в `local.properties` (`sdk.dir=C:/Android/Sdk`), файл в git не попадает.

```sh
cd mobile/android
./gradlew testDebugUnitTest assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Это отладочная сборка с отладочной подписью: её можно поставить на любой телефон, разрешив установку из неизвестных источников. Для публикации нужна release-сборка с собственным ключом — его в репозитории нет и быть не должно.

Картинки всех экранов на виртуальном Pixel 5 с придуманными данными и без сети рисует Paparazzi. Он нужен только тестам и в APK не попадает:

```sh
./gradlew recordPaparazziDebug
```

Снимки появятся в `app/src/test/snapshots/images`, в git они не попадают.

В GitHub Actions сборку делает `.github/workflows/android-apk.yml`: при пуше в ветки `markdev/noctgram-android-*`, если затронута папка `mobile/android/`, или вручную. Артефакт `NoctGram-Android` содержит APK и хранится 7 дней.

## Проверки

`NoctApiTest` без сети и без устройства проверяет загрузку файлов (multipart, привязка к чату, отказ от небезопасных имён и типов), разбор и отбор cookie, запрет выхода за пределы `/api/` своего адреса, сохранение и восстановление сессии, выход по отклонённой сессии (и его отсутствие при неверном коде), тексты ошибок и отказ от не-JSON ответов. `ScreensTest` рисует ленту, все виды постов, чаты, переписку, комментарии, свой и чужой профиль, редакторы и вход. Вход на настоящем телефоне и работа с сервером проверяются вручную.
