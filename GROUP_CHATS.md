# Группы и секретные чаты

Откройте «Сообщения» → **+** слева от карандаша. Карандаш по-прежнему создаёт обычный личный диалог.

## Группы

- Название, описание, выбор первоначальных участников, до 200 человек с владельцем в обычных группах.
- Общая группа «Noctgram | Общение» автоматически добавляется существующим пользователям и новым личным аккаунтам после завершения регистрации. Владелец выбирается из доверенных администраторов. Для общей группы нет лимита в 200 участников; список в настройках показывает первые 200, включая текущего пользователя и владельца. Выход, архив и исключение сохраняются.
- Приватная группа доступна по приглашению. Ссылка создаётся в настройках группы; новая ссылка отменяет предыдущую. На сервере хранится только хеш токена приглашения.
- Публичная группа получает отдельный @юзернейм: 4–24 латинских символа, цифры и `_`, начиная с буквы. Её можно найти через общий поиск. Адрес: `/?group=username`.
- Текстовые сообщения, ответы, удаление своих сообщений, непрочитанные сообщения и просмотр истории страницами по 100 сообщений.
- Владелец назначает администраторов и передаёт владение. Администраторы управляют участниками, оформлением группы и удаляют сообщения. Удалённый администратором участник не может вернуться по старой или новой ссылке.
- Перед удалением аккаунта владелец передаёт группы с другими участниками. Свои группы и доступные сообщения включаются в JSON-архив аккаунта, с повторной проверкой доступа на каждой странице.
- Права, блокировки аккаунта и ограничения отправки проверяются сервером при записи. Повторная отправка одного сообщения не создаёт дубликат.

Это первая версия групп: текст и ответы. Медиа, голосовые сообщения, групповые звонки и push для новых типов чатов пока не подключены. Обычные личные диалоги используют прежние функции.

## Секретные чаты

Это отдельный разговор на двух человек со сквозным шифрованием текста. Получатель принимает чат в своём браузере. Для каждого чата создаются собственные ключи; сообщения шифруются до отправки на сервер. Ключи устройства хранятся в IndexedDB и не отправляются на сервер.

В заголовке чата можно открыть код сверки. Сравните его лично или через другой доверенный канал. История доступна только в подключённых браузерах: очистка данных сайта или потеря устройства может сделать её невосстановимой. На другом устройстве создайте новый секретный чат.

Протокол пока не прошёл независимый аудит; автоматической смены ключей после каждого сообщения и forward secrecy нет. Обычные группы и личные диалоги не становятся сквозно зашифрованными. Технические подробности и границы защиты: [SECRET_CHATS.md](SECRET_CHATS.md).

## Подключение и проверка

Для общей группы примените миграцию `drizzle/0043_default_community_group.sql` по текущему журналу миграций. Она добавлена после уже опубликованных обновлений; старые записи журнала менять не нужно. Если доверенного администратора ещё нет, группа создастся после его назначения. База пользователей и существующие диалоги сохраняются.

Новая добавочная миграция: `drizzle/0032_chat_rooms.sql`, четыре таблицы `chat_rooms`, `chat_room_members`, `chat_room_messages`, `chat_room_invites`. Существующие миграции изменять не требуется. В текущей локальной базе миграция уже применена после резервного копирования; перед публикацией примените её также к целевой базе обычным процессом миграций проекта.

Проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`. Изолированные тесты включают SQLite, настоящий workerd/D1, HTTP-маршрут, ограничения доступа, приглашения, роли, удаление аккаунта, экспорт и реальное шифрование Web Crypto. Тесты не используют реальные аккаунты или внешние почтовые/платёжные сервисы.

Для подключения с другого устройства нужен HTTPS. `localhost` подходит для разработки на этом компьютере; доступ по обычному HTTP-адресу в локальной сети не предоставляет необходимые браузерные криптографические API.
