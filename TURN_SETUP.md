# Cloudflare TURN для звонков NoctGram

Код подключения готов. В локальном `.env` выбран `NOCT_TURN_PROVIDER=cloudflare`, но ключи пока пустые: сейчас доступно только прямое соединение через STUN. Для звонков между разными сетями нужно заполнить два серверных параметра.

## Подключение

1. Открой Cloudflare Dashboard → **Realtime → TURN** и создай TURN key. Сохрани его **Key ID** и **API token**. Нужен токен именно этого TURN key.
2. В локальном `.env` заполни:

   ```dotenv
   NOCT_TURN_PROVIDER=cloudflare
   NOCT_CF_TURN_KEY_ID=идентификатор_ключа
   NOCT_CF_TURN_API_TOKEN=токен_ключа
   ```

   `.env` исключён из Git. На хостинге эти же значения задаются в серверных секретах приложения. У них не должно быть префикса `NEXT_PUBLIC_`.

3. Перезапусти приложение: `npm run dev`. Для подключения друга нужен один общий HTTPS-адрес с общей базой. Два отдельных localhost не соединяют аккаунты между собой.
4. Начни аудиозвонок. Приложение запросит временные TURN credentials на три часа. Постоянный токен остаётся на сервере. При неполной конфигурации или ошибке провайдера приложение сообщит об ошибке подготовки соединения.

Используется [официальный API генерации credentials](https://developers.cloudflare.com/realtime/turn/generate-credentials/). Браузер получает разрешённые [адреса Cloudflare TURN](https://developers.cloudflare.com/realtime/turn/), включая UDP, TCP и TLS, если они возвращены провайдером. Порт 53 исключён как несовместимый с браузерами.

## Проверка настоящего соединения

- Два аккаунта, два устройства, общий HTTPS-адрес. Одно устройство подключи к Wi-Fi, другое — к мобильной сети. Проверь звук в обе стороны и выключение микрофона.
- На Chromium открой `chrome://webrtc-internals` до звонка. У выбранной ICE-пары тип `relay` подтверждает использование TURN; тип `host` или `srflx` означает прямое соединение. Само получение credentials ещё не проверяет передачу звука через TURN.
- Во время разговора отключи сеть на 5–10 секунд и включи снова. Повтори при переходе Wi-Fi → мобильная сеть. Интерфейс должен показать восстановление связи и вернуться к разговору.
- Проверь отмену во время подключения микрофона, быстрый сброс исходящего вызова, принятие на другом устройстве, закрытие вкладки и повторный звонок.
- Если соединение не восстановится примерно за минуту, звонок завершится с понятной ошибкой. Закрытая вкладка или приостановленный браузер телефона не гарантируют фоновый приём звонка.

Автоматические тесты проверяют сигналы, повторы, восстановление и выдачу credentials с подменённой сетью. Реальный звук и работу TURN между устройствами нужно проверить после добавления ключей.

## Обновление существующей базы

Если применены миграции 0000–0014, применить только новые 0015 и 0016, затем запустить новую версию приложения:

```powershell
npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0015_warm_doctor_faustus.sql
npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0016_broad_kree.sql
```

Для новой базы применить все миграции по порядку из `drizzle/meta/_journal.json`. Повторно запускать уже применённые `ALTER TABLE` не нужно. На удалённой базе использовать её рабочую конфигурацию и предварительно сохранить резервную копию.

## Восстановление и доступ

У каждого согласования соединения есть номер. Повторная отправка того же SDP или ICE-события безопасна, устаревшие ответы не заменяют новые. Инициатор создаёт новое предложение при обрыве, получатель может запросить перезапуск. Короткие сетевые ошибки повторяются; медленный запрос к TURN не останавливает heartbeat звонка.

Сервер выдаёт TURN credentials только участнику принятого звонка на его устройстве и повторно проверяет доступ после ответа Cloudflare. Отмена вызова учитывается даже тогда, когда запрос начала ещё находится в пути. Аккаунты, настройки приватности и чёрный список продолжают ограничивать звонки.

Вместо Cloudflare можно сохранить свой coturn: `NOCT_TURN_PROVIDER=coturn`, `NOCT_TURN_URLS` и `NOCT_TURN_SECRET`. Тестовые Premium и Stars этим обновлением не отключаются.
