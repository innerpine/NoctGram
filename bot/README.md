# Noct Stars · Telegram-бот

Бот живёт рядом с сайтом и пополняет **только тестовые Noct Stars**. Денег и Telegram Stars он не списывает: платёжных методов, счетов и подтверждения платежей в этом runtime нет.

## Что умеет

- Привязка личного Telegram к аккаунту Noctgram через одноразовую ссылку и код из чата.
- Баланс, пакеты 100–10 000 звёзд, подтверждение и последние 10 пополнений.
- До 50 000 тестовых звёзд за скользящие 24 часа. Лимит учитывает и аккаунт сайта, и Telegram даже после отвязки.
- Одно редактируемое меню, настройки сворачиваемых блоков, премиум-эмодзи с обычными запасными иконками и закреплённый статус по желанию.
- Начисления видны в общей истории Noct Stars на сайте; баланс обновляется при возвращении в его окно.

## Уже настроенный локальный проект

В двух терминалах из корня проекта:

```sh
npm run dev
npm run dev:bot
```

Затем на сайте **Noct Stars → Привязать Telegram**. Открой полученную ссылку, нажми «Старт», введи код бота на сайте. Вернись в бот и нажми «Проверить привязку», затем выбери пакет и подтверди.

Запускать один процесс бота. Он отвечает, пока компьютер, сайт и `dev:bot` работают. На телефоне `localhost` не открывает сайт на компьютере, поэтому до появления общего HTTPS-адреса бот предлагает вернуться в браузер на компьютере, без неработающей веб-кнопки.

## Первое подключение после клонирования

1. Установи зависимости проекта (`npm ci`, Node 22.13+).
2. Примени миграции сайта до `0010_past_chat.sql` включительно. Для существующей базы с миграциями 0000–0009 нужна только новая:

   ```sh
   npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0010_past_chat.sql
   ```

3. Скопируй `bot/.env.example` в `bot/.env`, укажи `TELEGRAM_BOT_TOKEN` от BotFather. Это отдельный файл: токен не должен попасть в env сайта.
4. Выполни `npm run setup:bot`. Скрипт проверит бота, запишет общий секрет в локальные env сайта и бота, установит username на сайте, команды и описание в Telegram. Повторный запуск сохраняет существующий общий секрет.
5. Перезапусти сайт и запусти `npm run dev:bot`.

`bot/.env`, корневая `.env` и `bot/data/` игнорируются Git. Не передавай их другу: для разработки он подключает отдельного бота к своей локальной базе. Для совместного использования одного бота нужен один сервер сайта и один polling-процесс.

## Настройки

| Файл       | Переменная                | Назначение                                                          |
| ---------- | ------------------------- | ------------------------------------------------------------------- |
| `bot/.env` | `TELEGRAM_BOT_TOKEN`      | Только доступ runner к Bot API                                      |
| `bot/.env` | `NOCT_SITE_URL`           | Корневой адрес сайта; HTTP разрешён только для loopback             |
| оба env    | `NOCT_BOT_SECRET`         | Отдельный секрет API пополнений, не токен Telegram и не jobs secret |
| оба env    | `NOCT_BOT_TEST_MODE=1`    | Явно включает тестовое пополнение                                   |
| env сайта  | `NOCT_BOT_USERNAME`       | Username без `@`, устанавливается setup                             |
| `bot/.env` | `NOCT_BOT_CUSTOM_EMOJI=1` | Включить возможность настройки custom emoji                         |

По умолчанию используются обычные иконки. Custom emoji включай, когда бот имеет соответствующее право Telegram. Реестр ID — `bot/screens.mjs`; PNG из веб-приложения нельзя использовать как Telegram emoji ID. Если Telegram отклоняет разметку custom emoji, runner возвращается к обычным иконкам. Настройки конкретного чата и положение меню сохраняются локально в SQLite.

## Дизайн

Адаптация присланного `DESIGN (1).md` описана в [DESIGN.md](DESIGN.md). В чатах Telegram нельзя применять CSS или произвольные цвета: используются HTML-разметка, встроенные стили кнопок и иконки. Цвета стандартных кнопок зависят от клиента и темы Telegram.

## Целостность данных

- Deep link содержит случайный токен на 10 минут, в базе хранится только hash. Кто-то, открывший пересланную ссылку, не сможет подтвердить привязку без доступа к обеим сторонам: сайту и коду из личного Telegram.
- Код из 8 цифр ограничен пятью неверными попытками. Сайт никогда не возвращает его или hash через GET.
- Связь уникальна по Noctgram ID и Telegram ID. Username — только подпись. Отвязка отзывает незавершённые пополнения, новый link ID не оживляет старые кнопки.
- Сумма и получатель определяются серверной записью пакета. D1 транзакционно добавляет `star_transfers.kind=telegram_test` и подтверждает квитанцию. Один order ID начисляется один раз, включая повторную доставку Telegram.
- Заблокированным и read-only аккаунтам новые привязки и пополнения недоступны. Отмена и отзыв доступны через собственную сессию сайта.
- Локальный cursor обновляется после обработки; потеря ответа Telegram после начисления не дублирует звёзды.
- API `/api/bot` принимает только ограниченный JSON POST с отдельным секретом. Ни браузер, ни публичные данные профиля не содержат этого секрета.

При сбоях сети runner повторяет обработку с задержкой. Telegram хранит необработанные обновления ограниченное время, поэтому эта локальная версия не является постоянно доступным сервисом. Существующий webhook автоматически не удаляется.

## Проверки

```sh
npm run test:bot
npx tsc --noEmit
npm run lint
npm run build
```

Интеграционные проверки выполняются **только на отдельной локальной базе** со всеми миграциями, по образцу остальных тестов проекта:

```sh
npx wrangler dev --config dist/server/wrangler.json --ip 127.0.0.1 --port 8787 --persist-to work/features-qa --var NOCT_BOT_TEST_MODE:1 --var NOCT_BOT_USERNAME:NoctgramQaBot --var NOCT_BOT_SECRET:qa_telegram_bridge_secret_32_chars_for_tests
node tests/telegram.integration.mjs
```

Последняя строка secret — публичное значение исключительно для изолированного QA, не настройка работающего бота. Тесты не обращаются в Telegram и не отправляют сообщений людям.

## Перед настоящими платежами

Нужна отдельная реализация: серверная проверка Telegram Stars платежей, уникальные charge ID, сверка сумм, возвраты и поддержка, а также отделение тестовых звёзд от платных. Переключателя «начать брать деньги» здесь нет. На публичном сайте тестовые пополнения должны оставаться отключены, пока не определены правила тестовой валюты и доступа.

Официальные источники: [получение обновлений](https://core.telegram.org/bots/api#getupdates), [deep links](https://core.telegram.org/bots/features#deep-linking), [кнопки и custom emoji](https://core.telegram.org/bots/api#inlinekeyboardbutton), [лимиты Telegram](https://core.telegram.org/bots/faq#my-bot-is-hitting-limits-how-do-i-avoid-this).
