# NoctGram · Telegram bot

Покупки Noct Stars и Noct Premium за Telegram Stars. Premium действует 30 дней и стоит 75 Telegram Stars. Crypto Pay доступен отдельно на сайте: Premium 149 ₽. Все пакеты, настройки и ограничения описаны в [COMMERCE.md](../COMMERCE.md).

Запуск из корня: `npm run dev`, затем `npm run dev:bot`. Привязка аккаунта: сайт → Noct Stars → Telegram. После привязки повторный `/start` открывает новую панель.

Публичный сайт использует Cloudflare Worker и webhook — постоянно включённый компьютер не нужен. Настройка и обновление: [CLOUDFLARE.md](CLOUDFLARE.md). Long polling ниже предназначен для локального запуска с отдельным ботом; не запускайте его с токеном публичного webhook-бота.

Команды: `/start`, `/topup`, `/premium`, `/history`, `/settings`, `/terms`, `/paysupport`. В оплате нет автопродления. Бесплатные активации и пополнения выключены по умолчанию; исторические балансы сохранены.

Администраторы из `NOCT_BOT_ADMIN_IDS` открывают `/admin` в личном чате: баланс бота в Telegram Stars и пополнения Noct Stars с момента включения уведомлений. Доступ проверяется по числовому Telegram ID, независимо от привязки аккаунта сайта и username. Панель не выполняет списания или возвраты.

`NOCT_BOT_ADMIN_NOTIFICATIONS_SINCE` — постоянная ISO-дата начала уведомлений. После подтверждённого начисления администратору приходит сообщение с количеством Noct Stars, оплаченных Telegram Stars, ID покупателя и заказа. Сверка восстанавливает пропущенные события; очередь сохраняется при перезапуске и повторяет неудачные отправки. Квитанции одного заказа не создают новые уведомления после подтверждённой доставки. При неоднозначном сетевом сбое после отправки Telegram может принять повтор: у `sendMessage` нет ключа идемпотентности. Настройка не рассылает старые покупки до указанной даты. Возврат до отправки отменяет ожидающее уведомление; возврат лишнего списания не отменяет успешно начисленный заказ.

Секреты — только в игнорируемых `.env` и `bot/.env`. `npm run setup:bot` синхронизирует bridge и описание; не включает тестовый режим автоматически. Бот использует long polling, поэтому localhost подходит без публичного webhook. Сайт и процесс бота должны оставаться запущены.

Проверка состояния: `npm run bot:status`; локальный просмотр обращений оператором: `npm run bot:status -- --support`. Квитанции, очередь обновлений и отметки сверки сохраняются в `bot/data/state.sqlite`. Перед переносом остановите процесс и сохраните эту папку вместе с базой сайта.

Оплата подтверждается только событиями Telegram или проверенной квитанцией провайдера. Счета/получатели фиксируются сервером; повторная доставка не повторяет начисление. Сверка Stars-транзакций и Crypto Pay работает отдельно от обработки pre-checkout. `/paysupport` не выполняет возврат автоматически.

`npm test` запускает изолированные тесты без настоящих списаний.
