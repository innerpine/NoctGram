# noct stars · чат-интерфейс

Адаптация предоставленного `DESIGN (1).md` для Noctgram. Из исходника взяты структура экрана и интонация; названия другого бота, модели, тарифы и AI-функции не переносятся.

- Заголовок: постоянная иконка + жирный текст, затем пустая строка. Все служебные строки строчными, обращение на «ты», без финальной точки.
- Основные экраны меняют одну панель через `editMessageText`. Если пользователь удалил её, бот создаёт новую. Отдельный закреплённый статус включается в оформлении по желанию.
- Короткое объяснение, затем сворачиваемый блок с суммой, аккаунтом и условиями. Форматирование блоков можно выключить.
- `·` разделяет поля, `—` поясняет, `›` обозначает переход. Выбор подтверждается `✓` и встроенным стилем `success`; выключенная опция — `✕` и `danger`.
- Главные действия и пакеты занимают полную строку. Второстепенные действия — по два в строке. На вложенных экранах последней строкой идёт единая кнопка возврата.
- Пакеты 100–10 000 Noct Stars. На каждой кнопке явно написано «бесплатно»; конкурентские цены в Telegram Stars не используются. Перед начислением отдельное подтверждение суммы и профиля.
- Noct Stars и Telegram Stars различаются в тексте: бот выдаёт тестовые Noct Stars, без счёта и без списания Telegram Stars.
- Иконки имеют обычный Unicode fallback. ID custom emoji из референса собраны в `screens.mjs`, их можно заменить собственными после создания Telegram emoji. Использование выключено по умолчанию до подтверждения доступа бота.
- Привязка показывает код только в личном Telegram. На сайте пользователь сверяет имя/ID и вводит код; «Проверить привязку» не подтверждает её автоматически.
- Ошибка — короткая понятная строка в той же панели и кнопка «назад». В историю попадают успешные пополнения, пустой экран говорит «пока нет пополнений».

Основные экраны: приветствие без привязки → код → баланс → пакеты → подтверждение → успех. Дополнительные: история, оформление, помощь.

Веб-карточка в Noct Stars использует существующие тёмные поверхности, тонкую границу, мягкое появление и состояния ожидания. Новые модальные слои не нужны.
