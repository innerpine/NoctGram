# Noctgram

Веб-приложение с лентой и личными диалогами. Интерфейс — по новой DESIGN.md (монохромные токены Dotify) и структуре Unixgram. Старый HTML-макет и обои не используются.

## Реализовано

- Публикации текста, до 4 фото/видео (25 МБ на файл), опросы на 2–6 ответов.
- Лайки, комментарии, сохранённое, поиск, подписки, лента с догрузкой.
- Профили: имя, описание, аватар, обложка, до 5 уникальных юзернеймов, выбор основного.
- Личные диалоги, непрочитанные сообщения, отметки прочтения; обновление каждые 3 секунды при открытом диалоге.
- Серверная идентификация ChatGPT / Sites, проверки авторства; D1 для данных, R2 для медиа.
- Адаптивное меню, клавиатурный поиск Ctrl/Cmd+K, доступные диалоги редактирования и подтверждения удаления.

## Разработка

Node 22.13+; `npm ci`, `npm run dev`. Локальный вход через ссылку «Войти» использует предусмотренную Sites тестовую учётную запись. Данные локального окружения не копируются в размещённый сайт.

Локальная схема: `npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0000_last_freak.sql`.

Проверки: `npx tsc --noEmit`, `npm run lint`, `npm run build`. Вендорные components/ui и use-mobile исключены из линтинга приложения; поставляются неизменными со стартером.

`node tests/api.integration.mjs` проверяет API через dev-сервер с локальной тестовой сессией. `node tests/messages.integration.mjs` проверяет три тестовых аккаунта через локальный production Worker на 8787. Тесты создают только локальные данные; не запускать на рабочем размещённом сайте.

## Размещение

Настройки логических привязок — `.openai/hosting.json`. Миграции — `drizzle/`. Sites обеспечивает доверенные заголовки пользователя; не выставляйте сырой Worker наружу в обход платформенной аутентификации. Первое размещение приватное. Для общения с другими людьми потребуется изменить аудиторию сайта.

## Границы первой версии

Noct Premium и покупки — TODO, без оплаты и активируемой подписки. Переписка без сквозного шифрования; сообщения хранятся на сервере. Stories, звонки, группы, боты, платежи и обработка/транскодирование видео не входят в эту версию. Фото и видео — исходные файлы, поэтому воспроизведение кодеков зависит от браузера.

Перед массовым публичным запуском: антиспам, квоты, жалобы и модерация, политика хранения/удаления медиа, восстановление аккаунтов и нагрузочные испытания. Удаление публикации удаляет связанные лайки/комментарии/голоса; уже загруженные медиа пока остаются в хранилище.
